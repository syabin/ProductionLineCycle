
# 生产线产能节拍甘特图系统

一个面向生产排程的**单文件 Web 工具**：用甘特图可视化各设备的工序排布，自动计算理论产能、稳态产能、线平衡率，并定位产线瓶颈，帮助快速评估与优化生产线节拍（Cycle Time）。

> 纯前端实现，无需后端。打开即用，数据自动保存在浏览器本地。

---

## ✨ 功能特性

- **工序库（模板库）**
  - 按「系列 → 型号 → 工序步骤」三级组织可复用模板。
  - 支持新增 / 编辑 / 删除 / 复制型号，型号内含标准工序步骤。
- **拖拽式排程甘特图**
  - 从左侧工序库把「型号」拖到画布即可生成一个设备排程。
  - 工序块可整体拖动调整开始时间，拖边缘调整持续时长（分钟）。
  - 设备行可删除、清空全部。
- **产能自动计算**
  - 理论产能 / 小时（批）
  - 稳态产能 / 小时（批）
  - 线平衡率（Line Balance Rate）与平衡柱状图
  - 瓶颈工序识别（标红 ⚠，线平衡率 < 70% 时给出瓶颈预警与优化建议）
  - 累计进料 / 出料、最大容量、流水线填充时间等
- **产能曲线图**
  - 三种视图：流向图、容量图、分设备图，可切换、可缩放。
  - 时间轴悬浮提示：某时刻的进料速度、出料速度、设备容量。
- **设备上下游关联**
  - 设备可设置上游 / 下游设备。
  - 标记为「进料」的工序，可自动关联并使用上游设备的出料速度（🔗）。
  - 支持「同时进出料」开关。
- **单位与密度**
  - 支持 `L`（升）与 `KG`（千克）单位，按密度（kg/L）自动换算。
- **导入 / 导出**
  - 导出 / 导入 **JSON** 项目文件（含工序库 + 排程）。
  - 导出 **Excel**（4 个工作表：设备列表 / 工序详情 / 工序库 / 产能统计）。
- **主题与本地化**
  - 深色 / 浅色主题一键切换，偏好记忆。
  - 全中文界面，时间单位统一为分钟（min）。

## 📖 使用说明

### 1. 搭建工序库（左侧）
- 「工序库」面板按系列分组，展开后显示各型号及其工序步骤。
- 用「+ 添加系列 / 添加型号」建立模板；型号内可增删工序步骤。
- 这些模板用于后续快速排程，可反复复用。

### 2. 排程（中间甘特图）
- 从工序库**拖拽一个型号**到右侧画布，即生成一个设备排程行。
- 拖动工序块移动其开始时间；拖动块左右边缘改变持续时长。
- 右侧「产能统计」面板会随改动**实时重算**。

### 3. 设备关联（编辑设备）
- 点击设备行进入编辑，可设置**上游 / 下游设备**、密度、是否同时进出料。
- 在工序上标记「进料 ⬆ / 出料 ⬇」，进料工序会自动拉取上游出料速度。

### 4. 查看计算结果（右侧）
- **产能参数**：瞬时进料 / 出料、累计进 / 出料、最大容量、理论产能、稳态产能。
- **线平衡分析**：平衡率、瓶颈 CT、平均 CT，逐项列出各工序节拍并标注瓶颈。
- **瓶颈预警**：平衡率偏低时给出瓶颈工序与优化建议。

### 5. 产能曲线（底部）
- 切换「流向 / 容量 / 分设备」视图，选择具体设备，鼠标悬浮查看任意时刻的进出料与容量。

### 6. 导入 / 导出（顶部菜单）
- `导入 / 导出 JSON`：整体备份与迁移项目（工序库 + 排程）。
- `导出 Excel`：生成含设备列表、工序详情、工序库、产能统计四表的报表。

## 📊 数据模型（简要）

```
工序库 lib[]
 └─ 系列 series { id, name, icon, models[] }
      └─ 型号 model { id, name, note, default_unit, default_density, can_concurrent_io, procs[] }
           └─ 工序步骤 proc { name, s(开始min), d(时长min), cap, in_speed, out_speed, unit, density }

排程 devs[]
 └─ 设备 dev { uid, name, note, unit, density, can_concurrent_io, upstream, downstream, procs[] }
      └─ 工序 proc { name, s, d, cap, in_speed, out_speed, unit, density, is_feeding, is_discharging }
```

关键字段含义：

| 字段 | 含义 |
| --- | --- |
| `s` | 工序开始时间（分钟） |
| `d` | 工序持续时长（分钟） |
| `cap` | 该工序/设备的容量 |
| `in_speed` / `out_speed` | 进料 / 出料速度（单位/min） |
| `unit` | 单位：`L` 或 `KG` |
| `density` | 密度（kg/L），用于 L↔KG 换算 |
| `is_feeding` / `is_discharging` | 是否为进料 / 出料工序 |

## 💾 本地存储

数据自动保存在浏览器 `localStorage`，无需手动保存：

| Key | 内容 |
| --- | --- |
| `lct_lib_v1` | 工序库 |
| `lct_devs_v1` | 排程（设备 + 工序） |
| `lct_theme` | 主题偏好（dark / light） |
| `lct_token` | 登录令牌（离线版默认免登录，本地用户 / 管理员） |

> 说明：代码内置了登录 / 注册 / 修改密码等接口（`/api/*`），但**离线版默认以本地用户身份直接进入，无需登录**。若对接后端服务，可设置 `API` 常量指向服务端地址。

---

## 📤 导入导出格式

- **JSON 项目文件**：结构为 `{ type: "lct-project", version: "1.0", t, lib, devs }`，可直接回灌。
- **Excel 报表**：包含 4 个工作表
  1. `设备列表`：设备名称、备注、单位、密度、是否同时进出料、上下游、工序数。
  2. `工序详情`：逐工序的开始 / 时长 / 容量 / 进出料速度 / 类型 / 密度。
  3. `工序库`：系列、型号、步骤数、步骤列表。
  4. `产能统计`：设备数、工序数、总时长、最大容量、理论 / 稳态产能、线平衡率、瓶颈工序。

## 🔧 开发与二次开发

- 全部逻辑集中在 `index.html` 的 `<script>` 中，核心计算函数为 `lct_calc_local(...)` 及其子函数（`lct_calc_totals` / `lct_calc_line_balance` / `lct_calc_throughput` / `lct_calc_device_cap_history` / `lct_calc_flow_connections`）。
- 如需接入账号体系，将文件顶部的 `API` 常量（`const TS = 5, API = '';`）设为后端地址，并提供对应的 `/api/login`、`/api/register`、`/api/logout`、`/api/change-password` 接口即可。
